# FileSorter 🧹

Простой и эффективный скрипт на Python для автоматического наведения порядка в папке загрузок (`Downloads`). Он сканирует указанную директорию и автоматически распределяет файлы по нужным папкам (Музыка, Документы, Картинки и т.д.) в зависимости от их расширения.

## ✨ Особенности

* **Игнорирование папок:** Скрипт перемещает только файлы, не трогая вложенные поддиректории.
* **Регистронезависимость:** Одинаково успешно обрабатывает как `.jpg`, так и `.JPG`.
* **Zero Dependencies:** Использует только встроенную библиотеку `pathlib`, не требуя установки сторонних пакетов.

## 📂 Как это работает (Правила сортировки)

По умолчанию файлы распределяются по следующим папкам в вашей домашней директории:
* **Music:** `.mp3`, `.mp4`
* **Documents:** `.doc`, `.docx`, `.pdf`, `.xlsx`, `.xls`
* **Pictures:** `.jpg`, `.jpeg`, `.png`, `.gif`, `.svg`

## 🚀 Быстрый старт

### Требования
* Установленный **Python 3.4+** (так как используется `pathlib`).

### Запуск
1. Клонируйте репозиторий или скачайте файл со скриптом:
   ```bash
   git clone https://github.com/venuxxx/path-sorter
   cd file-sorter
   ```
2. Запустите скрипт:
   ```bash
   python main.py
   ```

## 🛠 Настройка под себя

Вы можете легко изменить папку для сканирования или добавить новые расширения. Откройте `main.py` и отредактируйте переменные в начале файла:

```python
# Измените путь к папке, которую нужно очистить
WORK_DIRECTORY = Path().home() / "Desktop"  # Например, наведение порядка на Рабочем столе

# Добавьте свои правила сортировки в словарь EXTENSIONS
EXTENSIONS = {
    ".zip": "Archives",
    ".rar": "Archives",
    ".exe": "Programs",
}
